**Required property:** first distinguish need/constraint/symptom/question from explicit material authorization; if materially ambiguous, ask one focused clarification; local correction returns to valid cursor.  
**Current mechanism:** AGENTS authority boundary, workflow return semantics, quality/learning and the persisted 2026-09-18 learning.  
**Disposition:** **CONTROLLED NORM / REAL-USE REGRESSION RISK.** Do not create an intent ontology.  
**Work path:** #249 must include this in Human-decision/interaction validation.

### F44 — Persisted or reconciled learning is not automatically operationally enforced

**Observed failure:** after a learning was persisted as failure evidence, assistant language implied future reliable behaviour.  
**Required property:** assurance claim strength must match actual state: observed, persisted, reconciled, normative, executable/regression-tested and fresh-context demonstrated are distinct evidential claims.  
**Current mechanism:** quality/maintenance assurance already prohibits overclaim; no safe deterministic full-language test exists.  
**Disposition:** **CONTROLLED NORM / JUDGEMENT-BASED RESIDUAL.**  
**Work path:** #250 must ensure engineering CI/result language states only what it proves; #252 prompt tests must not call self-review independent proof.
