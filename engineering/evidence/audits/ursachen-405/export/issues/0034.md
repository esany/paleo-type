## Governing requirement
Measures, weights, currencies, numerals and accounting notation must be read as historically situated sign/value systems without silently converting uncertain manuscript notation into normalized modern values.

## Review criteria
Verify that the structure supports:
- written numeral/sign/form separately from interpreted numeric value;
- denomination/unit separately from quantity;
- abbreviations and accounting marks as source phenomena;
- uncertainty in sign reading, unit identification, conversion and semantic interpretation as distinct problems;
- period/place/institution-specific systems and changing equivalences;
- exact manuscript loci and same-hand/notational comparanda;
- external metrological/numismatic evidence from inspected reference works/sources;
- contextual plausibility only after sign-level evidence is preserved;
- alternative conversions/identifications where historical systems are ambiguous;
- provenance and version/date for conversion tables or reference systems when consequential.

## Experiential-knowledge check
Expert knowledge of historical coinage, measures, account practice and numeral conventions should guide candidate systems and comparison strategy, but must not turn an unclear sign into a value without graphical and contextual evidence.

## Measures if a gap is demonstrated
Possible minimal measures:
- keep separate fields/records for written form, interpreted unit/value and conversion;
- strengthen project notation concordances;
- add period/place-specific reference tables only when repeated use justifies them;
- attach source/provenance to conversion rules;
- route unusual notation to targeted specialist review;
- create reusable corpus-level structures only when multiple projects share the same system and duplicate work becomes material.

## Trigger
Review when notation/value interpretation becomes a recurring bottleneck, when calculations/comparisons depend on normalized values, when multiple historical systems coexist, or before publication claims based materially on money/measure conversions.

## Definition of Done
- original written notation remains recoverable and visible;
- sign reading, unit identification and value conversion are separately auditable;
- historical equivalences expose time/place/source scope;
- unresolved conversions remain unresolved rather than normalized by convenience;
- specialist review status is explicit for consequential uncommon systems.

## Do not
Do not replace manuscript numerals/currency/measure signs with modern values in the diplomatic layer. Do not build a universal metrology database before repeated research need demonstrates value.

### Architecture handoff

Later target representation must be able to preserve a chain such as `written sign/locus → candidate sign reading → unit/accounting function → interpreted historical value → optional conversion`, with independent evidence/status at each consequential step. Do not prebuild conversion tables; add period/place-specific references only when real calculations/comparisons require them. Reuse the common canonical locus/anchor mechanism from ARCH/PAL.

Overall: current notation discipline is a **strong partial implementation**; interpretation/conversion layers are the demonstrated future gap, not sign preservation.
