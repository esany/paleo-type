## Role in the redesign
This is the **first active scholarly-requirements issue**. Its output is not another methodology chapter. It establishes the evidence base against which #26–#35 derive requirements and against which #36/#37/#39 later derive architecture, AI/HITL and human-review structures.

## Governing question
What do the relevant disciplines currently require for reliable critical work on early-modern handwritten historical sources, and which parts come from:

- formal standards/guidelines;
- established disciplinary practice;
- empirical methodological evidence;
- experiential/tacit specialist knowledge;
- source/project-specific editorial choice;
- software/vendor/model practice?

Do not collapse these categories into generic “best practice”.

## Required output
Produce one concise reference-frame matrix used by all later domain issues:

`domain → authoritative/current references → core scholarly requirements → contested/source-specific areas → tacit expertise needs → material implication for later audit`

For every referenced standard/guideline record version/date where material and state its actual role:

`conceptual | working-method guidance | interchange | validation | publication | governance`

## Domains to establish
At minimum:
- archival science / diplomatics;
- palaeography / scribal evidence;
- historical philology / language history / lexicography;
- scholarly editing / textual criticism;
- historical source criticism;
- source-type/domain history;
- codicology / material manuscript study;
- onomastics / toponymy;
- historical metrology / numismatics / accounting notation;
- research-data stewardship / Good Research Practice;
- research software/data engineering where it bears on scholarly reliability;
- AI/HITL where it bears on evidence, validation and responsibility.

## Evidence hierarchy
Prefer, as applicable:
1. current primary standards/guidelines from responsible scholarly/professional bodies;
2. current authoritative disciplinary handbooks/guidance and peer-reviewed methodological literature;
3. demonstrated practice in high-quality comparable scholarly editions/projects;
4. documented expert judgement/experience where standards do not determine the case;
5. software/model/vendor claims only as implementation evidence, never scholarly authority.

## Audit questions
For each domain determine:
- which current authoritative references actually apply;
- what is consensus/core method versus a legitimate editorial/source-specific choice;
- what must be represented as information to avoid scholarly loss;
- what cannot be reduced to deterministic rules and needs expert judgement;
- what kinds of claims require independent human specialist review at high consequence;
- whether the repository currently overstates compliance or validation;
- whether existing repo rules reflect obsolete/duplicated interpretations rather than current requirements.

## Anti-bloat rule
Do **not** immediately edit `historical-source-workflow.md`, `AGENTS.md`, gates or schemas while doing this review. First establish the external/domain requirement. Changes are proposed only when a later domain audit demonstrates a concrete mismatch.

## Handoff to #26–#35
Each domain issue receives from #38 only the relevant reference-frame facts. It must then independently derive:

`requirement → why it matters → evidence basis → information needed → failure if absent → validation/judgement type`

The domain issue, not #38, decides whether the current repository satisfies the requirement.

## Definition of Done
- current authoritative reference frame is explicit and versioned where material;
- formal standards are distinguished from disciplinary practice and tacit expertise;
- contested/source-specific choices are not falsely normalized into universal rules;
- later domain audits can cite a stable baseline rather than repeating literature discovery;
- no repository structural change has been pre-authorized by this issue;
- independent specialist-review needs are stated where the evidence base itself cannot resolve practice questions.

## Do not
- no citation-only refresh;
- no TEI/RiC/FAIR/GWP/AI framework treated as a universal quality certificate;
- no technology recommendation before an information/epistemic requirement exists;
- no freezing of the 2026 standards landscape as permanent method.

### Important classification findings

1. **Standards are heterogeneous.** ICA/TEI/IIIF are chiefly conceptual/representation/interoperability frameworks; DFG/ALLEA are governance/integrity frameworks; IDE/RIDE is disciplinary evaluation practice. They must not be collapsed into one generic `compliant/not compliant` status.
2. **No standard fetishism.** TEI, RiC, FAIR, IIIF or AI-governance compliance cannot by itself establish scholarly adequacy.
3. **Several decisive domains are judgement-led.** Palaeography, philology, historical source criticism, onomastics and historical metrology retain substantial source-specific/tacit expert components. Later audits must identify where procedural evidence is sufficient and where independent specialist escalation is warranted.
4. **Representation vs inference must remain separate.** A standard may tell us how to represent a hand, person, layout, record relation or uncertainty; it does not make the underlying scholarly identification true.
5. **Current-version correction for the repo audit:** any later issue relying on TEI should use P5 4.12.0 (2026-07-28), not an older unversioned reference. RiC review must include the 2025 Application Guidelines, not only RiC-CM/RiC-O.

## Phase A1 reference-frame baseline — pass 2: judgement-led domains

This supplements the standards matrix with concrete scholarly reference anchors for domains that are not governed by one formal standard. These are **evidence/reference resources**, not automatic authorities for a particular reading.

### Historical philology / lexical-semantic work
- **Frühneuhochdeutsches Wörterbuch (FWB-online)** — project of the Niedersächsische Akademie der Wissenschaften zu Göttingen; covers High German vocabulary from the mid-14th to mid-17th century and is directly period-relevant to the current early-modern corpus.
- **Deutsches Rechtswörterbuch (DRW)** — Heidelberg Academy; historical German/West Germanic legal vocabulary, including Early New High German, with a large historical evidence corpus and coverage that also includes coins, weights and measures where legally relevant.

Implication for #28: historical dictionaries/corpora can test lexical forms, meanings and period usage **after** graphematic evidence has been preserved. Dictionary attestation or semantic fit must not by itself upgrade a manuscript reading.

### Onomastics / toponymy
- **Ortsnamen zwischen Rhein und Elbe — Onomastik im europäischen Raum** (Göttingen Academy) demonstrates current scholarly practice: historical name attestations are collected over time, prior interpretations are reviewed, and names are analysed etymologically, morphologically and typologically from historical evidence rather than string matching.
- **Digitales Familiennamenwörterbuch Deutschlands (DFD)** (Academy of Sciences and Literature Mainz / names research infrastructure) is a current large-scale scholarly reference for family-name etymology and distribution; useful as a reference resource, but its modern-name scope does not make it direct evidence for a 16th-century person identification.

Implication for #33: preserve source form and identification separately; use historical attestations, chronology/geography and linguistic derivation; authority-file/string agreement alone is insufficient.

### Historical source criticism
- **Living Handbook Digitale Quellenkritik**, v1.1 introduction (2024), explicitly treats source criticism as the central historical-critical method and extends reflection to digitally mediated sources; it is a current reviewed methodological resource, not a formal standard.
- **Handbuch der Historik** (Springer VS, 2025) is a current broad handbook anchor for historical theory/method, explicitly including Quellenkritik among its core topics.

Implication for #30: the audit must preserve the classic distinction between source/text establishment and criticism of source statements while also treating digital mediation, selection, transformation and access conditions as part of the evidential situation. No software/data standard can substitute for source-critical judgement.

### Palaeography / codicology
- **CIPL / IRHT** remain central disciplinary infrastructures; CIPL's long-running work on dated manuscripts and terminology provides comparison resources rather than a deterministic classifier.
- **Vocabulaire codicologique** under CIPL patronage remains a terminology anchor.
- The 2025 CIPL colloquium `Scribes and Hands: Old and New Methods of Scribal Identification` confirms that hand/scribe identification remains an active methodological research problem rather than a settled rule system.

Implication for #27/#32: later requirements should emphasize inspectable comparison evidence, explicit feature description, and separation of observation from attribution. A classifier/model output cannot be elevated to independent palaeographic validation merely because it is reproducible.

### Historical metrology / numismatics / accounting notation
No current universal cross-regional standard was found that can safely normalize early-modern values. This is itself a material baseline finding. The DRW can provide historically evidenced lexical/legal contexts for many coins, measures and weights, but conversion/identification must still be tied to time, place, jurisdiction/source type and notation system.

Implication for #34: the canonical requirement should likely be to preserve the written notation/sign and contextual identification separately, with normalization/conversion as a sourced interpretation. Do not build a universal conversion table from generic modern references.

### Source-type/domain history
No generic formal standard should be sought here. The governing evidence is source-type-specific scholarship and archival/historical context. For the present corpus, later #31 should activate ecclesiastical/administrative/visitation scholarship only where a concrete source feature or historical claim requires it.

### Result of pass 2
The baseline is now sufficient for the later domain issues to **avoid repeating framework discovery**:
- formal standards/guidelines are identified where they exist;
- current version changes are recorded;
- judgement-led domains have concrete scholarly reference anchors;
- domains with no universal standard are explicitly marked as such rather than filled with a pseudo-standard.

Remaining work in #38 is now limited to a short synthesis/DoD check and deciding whether any material reference family is still missing. No repository method or data structure has been changed.
