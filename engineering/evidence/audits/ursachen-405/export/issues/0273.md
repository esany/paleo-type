Implements the admitted bounded acquisition MVP from #271 using the live-confirmed SStA pilot path:

## Restartability / execution-control correction

Following #276/#277 and the Human-Owner D-016 `ADMIT` recorded for #285, the acquisition core writes durable `ACQUISITION_STATE.json` progress in the configured external destination after each newly verified image.

- ordinary interruption leaves truthful `partial-restartable` state rather than discarding prior verified progress;
- operator cancellation leaves `cancelled-restartable` state;
- resuming the same provider-list/route plan verifies persisted completed images locally and skips their network download;
- a changed/corrupt recorded file fails closed before network retry can hide the mismatch;
- untracked pre-existing bytes are adopted only after a newly downloaded remote copy hashes identically;
- repository/worktree output is rejected;
- `--status` is a read-only path over persisted progress and does not fetch images or mutate the package;
- the `savesax` skill separates status/read from a new acquisition/resume request and rejects disposable CI storage as a default productive preservation destination.

This is an owner-local implementation of the admitted shared execution-control properties; it is not a workflow engine or generic job service.

## Productive runtime correction

The former hosted-runner live-acquisition workflow has been **removed**. GitHub Actions is used only for deterministic repository assurance here; it is not retained as a production archival-acquisition path merely because it can execute the script.

A full productive run may start only after the intended external destination/runtime is shown fit for the required persistence, restart/resume and Human-control properties. No full live acquisition is started by this PR update.

## Chat skill

- Repository-scoped skill at `.agents/skills/savesax/SKILL.md`: bare `savesax` is a complete acquisition request; it reuses one current source URL and asks only for a missing link or external destination.
- Status wording such as `Fertig?`/`Status?` is explicitly read-only and must not trigger a new run.
- UI metadata enables implicit invocation; explicit selectors are ChatGPT `@savesax` and Codex `$savesax`.
- CLI can take metadata through stdin, avoiding a sidecar file.
- The skill hard-stops on missing external storage and never writes images to the repository/worktree.
- No GitHub Actions production-download workflow is included.
