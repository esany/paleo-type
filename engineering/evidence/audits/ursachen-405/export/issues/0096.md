## Method correction: witness independence is not page isolation

- graphical features, not expected wording or semantic plausibility, drive the comparison;
- a later occurrence is not copied into the target merely because the word/name appears plausible;
- same-hand relevance is not assumed from same record/source and is stated conservatively where consequential;
- unresolved remains valid when the target graph does not discriminate.

## Per-locus scientific protocol
For each physical unit:
1. verify exact evidence object and visual inspectability;
2. establish physical/documentary structure, lineation and reading order before semantic reconstruction;
3. record the visible grapheme/sign sequence conservatively;
4. classify the problem where needed: grapheme, abbreviation, numeral/accounting sign, segmentation, source phenomenon, damage, addition/deletion, etc.;
5. form only graphically viable candidates;
6. test difficult candidates against relevant Reg. Ii 4 internal comparanda when useful, using discriminating letter/sign features rather than word silhouette;
7. use lexical/syntactic/domain context only after graphical candidate formation and never as a substitute for manuscript evidence;
8. preserve written spelling, numerals/signs, abbreviations and layout-relevant phenomena;
9. keep source phenomena separate from research status and retain narrow `unresolved`/alternatives where evidence does not decide;
10. persist folio-local transcription data without duplicating stable Source/File/crosswalk truth;
11. update `STATUS.md` only when the canonical restart cursor/state actually changes.
