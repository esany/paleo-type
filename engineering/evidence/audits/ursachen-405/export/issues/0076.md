## Status / authority

**P1 role-definition / governance fixture. No external reviewer is appointed and no specific review is commissioned by this Issue.**

This Issue defines the reusable **Qualified Independent Specialist Review function** for cases where AI-assisted/method-compliant research is not sufficient to establish the desired validation level.

The role is deliberately distinct from Source Research (#72), Domain Review (#73), Dev (#74) and Human Owner/Governance (#75).

## Core purpose

Provide independent qualified judgement on a clearly bounded specialist question using an exact-source evidence packet and return that judgement with explicit validation scope, reasoning basis and residual uncertainty.

Use:

```text
Domain Review identifies consequential unresolved specialist question
→ bounded exact-source review packet
→ qualified independent specialist examines evidence
→ specialist judgement + limits
→ Domain Review integrates validation state
→ owner decides consequential use where applicable
```

## When this role is triggered

Use only when consequence or unresolved specialist judgement warrants independent review, for example:

- a palaeographic reading materially affects a consequential claim and cannot be adequately secured procedurally;
- hand attribution or scribal differentiation remains materially contested;
- a philological/editorial judgement requires domain expertise beyond current evidence-bound AI assistance;
- archival/diplomatic identification has consequential ambiguity;
- publication/reuse claims require a higher validation level;
- Domain Review explicitly identifies independent specialist review as the appropriate next step.

Do not trigger independent review for every uncertain token or routine working reading.

## Required review packet

The specialist should receive the smallest sufficient packet, containing as applicable:

```text
REVIEW QUESTION
one bounded specialist question

SOURCE IDENTITY
archive/source/file/locus and exact evidence locator

EVIDENCE
unprocessed source representation and any consequential derivative provenance

OBSERVATION / CURRENT READING
what is currently established and at what status

ALTERNATIVES
credible candidates or competing analyses already on record

CONTEXT
only context legitimately relevant to the review

PRIOR DECISIONS
where they materially affect the question

REQUESTED VALIDATION LEVEL
what the review is expected to establish or not establish

KNOWN LIMITS
access/image/material constraints
```

Do not contaminate an independent reading with unnecessary preferred-answer framing.

## Specialist authority

Within the bounded question, a qualified independent specialist may:

- provide an independent reading/assessment;
- reject or support existing candidates;
- identify additional alternatives;
- state that evidence is insufficient;
- recommend further evidence/comparison;
- explain disciplinary basis and limits;
- distinguish confidence from certainty.

The specialist does not automatically control project purpose, architecture, implementation or publication decisions.

## Independence / validation status

The review record must state enough to distinguish:

- AI-assisted source research;
- AI-assisted Domain Review;
- qualified independent specialist review;
- owner decision/consequential use.

Where independence is limited—for example the reviewer has already seen a preferred reading or participated in prior analysis—record that limitation rather than claiming stronger validation.

## Return package: Specialist → Domain Review

Return, proportionally to consequence:

```text
QUESTION REVIEWED

EVIDENCE INSPECTED
exact source/locator/derivatives actually used

SPECIALIST FINDING
reading/assessment or insufficient-evidence result

ALTERNATIVES / REJECTIONS
where material

BASIS
brief disciplinary/evidential reasoning

CONFIDENCE / LIMITS
residual uncertainty and material constraints

VALIDATION SCOPE
what this review does and does not validate

RECOMMENDED NEXT ACTION
if further evidence/review is needed
```

Domain Review then determines project/canonical-state consequences through the existing decision/re-adjudication path.

## Canonical-state boundary

A specialist review is evidence/review basis for a possible state transition; it does not silently overwrite canonical research state merely because it is authoritative.

Where a canonical reading/decision changes, preserve predecessor state, review basis, reason and supersession/revision provenance as required by the owning project method.

## Human Owner interface

The human owner is not asked to adjudicate the specialist question.

Where the specialist result affects consequential external use/publication, Domain Review presents the result and validation state to the owner, who retains the use/publication decision.

## Model-independent procedural principle

Different qualified specialists may legitimately disagree. Stable process elements should be:

- bounded review question;
- exact evidence packet;
- independence/validation status;
- explicit alternatives and limits;
- return package;
- canonical-state transition discipline.

Do not require specialist agreement or use review as a mechanism to force certainty.

## Relationship to #71

This Issue is the independent-specialist role fixture for the generic role/handoff blueprint.

## Acceptance criteria

- [ ] trigger is consequence-scaled rather than routine;
- [ ] exact-source review packet is defined without overloading the reviewer;
- [ ] independence and validation scope are explicit;
- [ ] specialist judgement may remain insufficient/unresolved;
- [ ] specialist result does not silently mutate canonical state;
- [ ] owner is not substitute specialist;
- [ ] Domain Review remains responsible for integrating the result into workflow/requirements;
- [ ] procedure remains usable across palaeographic, philological, archival and other specialist reviews;
- [ ] no requirement for forced expert consensus is introduced.

## Non-goals

- no automatic external-review requirement for all research;
- no reviewer registry/system;
- no publication workflow engine;
- no assumption that one specialist judgement is infallible;
- no transfer of architecture/governance authority to the specialist.
