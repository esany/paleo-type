# PR #45: Clarify project-relative source functions

## Text

Clarifies the already accepted D-012 semantics without introducing a new data layer or schema.

- treats each project source-register row as project-source membership plus project-relative function/locus;
- makes explicit that a source has stable corpus identity but no absolute research role;
- allows the same canonical source to be principal/control/context/etc. in different projects without corpus changes;
- distinguishes project-relative functions from source-to-source claims in corpus/relationships.tsv;
- clarifies that `comparison` means only use for comparison in that investigation unless a source relationship is independently evidenced.

The existing `sources.tsv` schema and `project_role` column are retained; this is a semantic clarification, not a new architecture.
