## Text

Corrects a modelling-level conflation discovered from the Knau source group.

Key correction:
- `ThHStAW, EGA, Reg. Ii 3 / stat_visitation_00000197 — Visitation in Jena, Neustadt an der Orla, Pößneck, Saalfeld` is the archival act/record, not the protocol/source-group identity used by the investigation.

Changes:
- project STATUS now distinguishes archival records/acts from protocol/source units;
- the 00000197 project row is marked `unit-unresolved` and no longer presents the act-wide extent as a resolved source-group locus;
- corpus README states the minimum hierarchy `holding/signature → archival record/act → protocol/source unit → witness/locus → digital instantiation`;
- resolver output labels the resolved object `archival_record` and surfaces unresolved protocol/source-unit status instead of silently equating it with the act title.

No protocol ID/title/boundary is invented. This is a semantic safety correction, not a new database/schema layer.
