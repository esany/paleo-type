## Governing requirement
The repository must support a scientifically defensible path from manuscript evidence to diplomatic transcription, witness comparison, apparatus and edition without creating parallel text truths or hiding editorial intervention.

## Review criteria
Verify that the structure can represent and preserve:
- archival locus and physical line/page structure;
- diplomatic written text separately from normalization/identification;
- uncertainty and source phenomena such as unclear text, illegibility/gap, supplied text, addition, deletion/cancellation and damage where observed;
- abbreviation sign separately from editor-provided expansion;
- witness independence before collation;
- explicit mapping of corresponding textual units across witnesses;
- variants, omissions, additions, order differences and structural divergences;
- consequential editorial decisions and revision history;
- an apparatus or equivalent transparent representation where materially required;
- a human-readable diplomatic witness view derived from canonical data rather than manually maintained twice;
- an explicit edition concept before final rendering;
- traceability from published/editorial output back to source locus and decision history.

## Standards / expertise check
At review time verify the then-current TEI P5 and relevant scholarly-edition guidance as conceptual/interchange references. The question is whether the working model preserves required scholarly distinctions and can map to established representations with acceptable loss—not whether the repository already uses TEI XML.

## Measures if a gap is demonstrated
Possible minimal measures:
- migrate the transcription schema only for source phenomena actually required by evidence;
- introduce deterministic generation of human-readable diplomatic views;
- strengthen witness/collation mapping or apparatus records;
- separate editorial expansion/supply from written text where currently conflated;
- formalize an edition profile/conventions document only when moving toward G6;
- implement TEI export only when the concrete trigger in #1 is reached;
- use publication validation controls when #7 is triggered.

## Trigger
Review before a canonical transcription-format migration, before producing a scholarly edition, when parallel witnesses become numerous/complex, when manual duplicate text views emerge, or when the current model cannot represent observed manuscript phenomena without ambiguity.

## Definition of Done
- a specialist can distinguish manuscript text, uncertainty, editorial intervention, normalization and variant evidence;
- every consequential editorial choice is auditable to source/evidence;
- witness texts remain independently recoverable;
- a non-specialist reader can access the principal diplomatic text without interpreting machine internals;
- publication/export does not introduce new undocumented readings;
- any adopted interchange standard is justified by a real scholarly need.

## Do not
Do not equate TEI adoption with editorial quality. Do not create a second manually maintained edition/transcription truth for convenience.

### Real Knau test

- `transcription/132.tsv`–`135.tsv` are explicitly legacy working data, not the final G2 representation; current STATUS lists lineation, source-phenomenon representation and the derived human-readable witness as open gaps.
- `apparatus/decisions.tsv` is a useful **decision history**, not yet a textual-critical apparatus. It preserves rejected semantic reconstructions and residual uncertainty, which should survive migration.
- The observed correspondence between Reg. Ii 5 and Reg. Ii 4 Bd. II is not yet detailed collation; therefore REQ-EDIT-005/007 are genuine later requirements but do not justify building a complex apparatus now.
- No edition concept is needed yet because the project is at active G2, not G6.

### Architecture handoff — not implementation

1. Reuse the cross-domain canonical locus/unit addressing requirement from #26/#27 rather than inventing an editorial-only address scheme.
2. The future principal-witness representation must preserve source phenomena and editorial intervention without loss (REQ-EDIT-002/003) and must deterministically generate the human witness view (REQ-EDIT-008).
3. `apparatus/decisions.tsv` contains valuable research history that any migration must retain, but it should not be confused with the later variant apparatus (REQ-EDIT-006 vs REQ-EDIT-007).
4. Collation needs a lean mapping of independent witness units and differences only when G4 work actually begins; no generalized apparatus/database is justified now.
5. TEI export remains a later interchange/publication option, not the canonical working-format decision.
