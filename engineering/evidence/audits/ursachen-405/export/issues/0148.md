## Scope

## Changes

- add `tools/regii5_visual_retrieval.py`, a local exact-crop visual retrieval baseline using OpenCV template matching;
- derive the authorized page pool only from the canonical Reg. Ii 5 crosswalk and verify the supplied source File SHA against `corpus/files.tsv`;
- require explicit `--activate-same-source-pool`; availability alone does not run retrieval;
- return only Source/File/folio/PDF-page/crop coordinates, render SHA and technical score/rank — no candidate words/readings;
- add regression coverage for same-source scope, explicit activation and non-reading candidate records;
- persist the bounded evaluation record with `wolff`, `pfarrer` and adversarial `80/So` visual controls, including candidate utility and cost-to-first-useful-discriminator metrics.

Decision recorded as **KEEP narrowly as Generator A baseline**, not as an exhaustive or general palaeographic retrieval system.
