## Scope

Implements only the first #139 step after completed #138: a **project-bounded, read-only/rebuildable Evidence-Packet prototype** for Reg. Ii 5 controls. No HTR channel, no F1 reading, no STATUS/TSV cleanup, no `project_context.py` contract change, no persistent cache/index/schema.

### Prototype

Adds `tools/regii5_evidence_packet.py` with explicit phase separation:

- `blind`: exposes only exact target/provenance/crosswalk addressing needed for source inspection; current diplomatic reading and candidate context are deliberately withheld;
- `explore`: requires a caller-supplied source-only observation, freezes it by SHA-256, then exposes a compact current TSV row plus the existing G4 Reg. Ii 4 mapping/rows as **candidate-generation-only** material with `diplomatic_evidence_weight = 0`;
- `adjudicate`: preserves the same bounded packet but can neither decide nor persist a reading and explicitly requires source-target reinspection.

The compiler does not import `STATUS.md` or `project_context.py`, and omits long TSV `evidence_note` audit prose from the runtime packet.

### Controls

Adds deterministic tests for:

- known hard controls: `nachkomung`, `sonsten`, `wolff`, `gemeinswalde`, `steinbruch`, `Beuelh`;
- phase separation and frozen observation;
- `62r-L19 80/So` adversarial control: blind phase does not expose the inherited reading; only after a frozen observation does G4-008 expose Reg. Ii 4 `308r-L19` with `... so wolff ...`, at zero diplomatic evidence weight;
- non-secure G4-012 correspondence: mapping notice is present but Reg. Ii 4 candidate text is not exposed;
- compiler cannot adjudicate/persist.

## Boundaries

This PR does **not** change any canonical diplomatic reading. In particular Reg. Ii 5 `62r-L19` remains `80 wolff...` until a separate target-pixel adjudication under #123.

It also does not alter the existing restartability/assurance contract. Any later change to `project_context.py`, STATUS-dependent regression semantics, canonical Render/Crop registry, or shared METHOD remains outside this PR and must follow the #138 change-class boundary.

Closes no research scope; advances #139 prototype only.
