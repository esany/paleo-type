## Purpose

Capture the proposed pattern for standardizing cross-chat/Slack coordination through a small stable ChatGPT Project-instructions bootstrap that loads current transport rules from the repository.

## What this adds

- a paste-ready candidate Project-instructions bootstrap;
- explicit separation of stable Project prompt vs dynamic repo policy;
- trigger-only loading for coordination actions rather than every chat turn;
- fail-closed behavior when coordination policy/owner state cannot be resolved;
- sender/receiver permalink transparency;
- candidate transport MUST/SHOULD/MUST NOT semantics kept out of the Project prompt;
- explicit note that no normative coordination-policy owner is admitted yet;
- adoption boundary requiring later Human-Owner decision before Project settings or METHOD are changed.
