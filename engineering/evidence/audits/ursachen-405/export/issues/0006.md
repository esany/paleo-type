# Issue #6: Future: corpus-level entity authority reconciliation

- Quelle: https://github.com/esany/paleo-type/issues/6

## Text

## Research benefit
Prevent duplicate/conflicting person/place/institution identities when repeated entities become a corpus-level problem.

## Why not now
Local stable IDs and existing entity tables are sufficient at current scale; broader authority reconciliation would add maintenance without solving an observed bottleneck.

## Trigger
Repeated entities cause actual duplicate/conflicting identifications, or external interoperability requires authority links.

## Definition of Done
- stable local entity IDs remain primary;
- optional external authority links are added only when verified;
- manuscript forms remain separate from normalized identities;
- conflicting identifications remain explicit, not auto-merged;
- no second entity truth store is introduced.

## Trigger review
Re-check when an identification conflict recurs across projects/sources or external authority interoperability is requested. Otherwise leave deferred.
