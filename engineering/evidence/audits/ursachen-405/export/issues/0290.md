## Purpose

Persist the holistic/source-first re-review of how `paleo-type` should support an unfamiliar historical manuscript from first contact through bounded scholarly work, independently of the existing #265–#269 bug decomposition.

This PR is the **current non-normative analysis / requirements / concept / planning surface** for that question. It supersedes draft PR #286 as the current planning surface while preserving #286 as provenance/history.

## Core conclusion

The actual gap is not one missing `Reconnaissance` stage or one missing state field. `paleo-type` needs an explicit **adaptive source-entry research capability** spanning the early S1–S4 region:

- orient: purpose/evidence + broad source reconnaissance;
- learn: source-specific structure/hand competence through diagnostic inspection and pilot reading;
- bound: distinguish Project root, inspection domain/coverage, discovered structure, active scholarly scope and transcription scope;
- explain/persist: expose discipline/evidence/claim ceiling/next discriminating action to the Human and preserve restart-relevant state.

The source-entry cycle must compress to a light pass for a short clear source and expand only when structure, relevance or legibility require it.

## Planning consequence

The review derives three new natural-owner work items rather than expanding the old symptom list:

1. generic source-entry METHOD semantics;
2. Human-visible scholarly action/competence-evidence routing;
3. one real Wolkenburg source-entry research fixture.

Existing #265–#269 remain natural owners for downstream scope/inspection/representation gaps, with explicit reframe/refine dispositions.
