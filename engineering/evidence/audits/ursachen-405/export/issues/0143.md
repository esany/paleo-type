## Purpose

Audit external historical-language and genre-specific resources that can broaden **candidate generation and contextual testing** for difficult early-modern German manuscript loci while preserving the project rule that lexical/domain plausibility is not manuscript reading evidence.

This is not authority to import external wording into canonical diplomatic transcription and not authority to bulk-ingest third-party data before reuse rights are known.

## Research finding to preserve

The current repo method already recognizes historical philology/lexicography, onomastics, metrology and domain history as valid specialist lenses after visible manuscript evidence is preserved. The current #123 execution path, however, uses them only narrowly. For difficult `62v` prose this may unnecessarily reduce the set of testable hypotheses.

Desired separation:

```text
visible target evidence preserved
→ external resource proposes historically attested forms/formulae/terms
→ candidate is tested against exact target graph
→ target graph remains reading authority
```

## Resources identified

### Frühneuhochdeutsches Wörterbuch (FWB-online)

- directly relevant chronological language resource for Early New High German;
- public web access is available;
- useful for historical spelling/morphology/lexical candidate testing;
- do **not** assume the complete data is open for bulk scraping, redistribution or model training without checking its terms/licensing.

Reference:
- https://fwb-online.de/

### Deutsches Rechtswörterbuch (DRW)

- public historical legal/administrative vocabulary resource with broader relevance to early-modern institutional, property, measure and everyday terminology;
- useful for source-type terminology and historically attested candidate forms;
- public lookup does not automatically imply unrestricted bulk reuse/training rights.

Reference:
- https://drw.hadw-bw.de/

### HTR-United

- open catalog for HTR ground-truth datasets;
- dataset metadata exposes licenses and transcription formats;
- individual datasets have their own licenses and must be screened individually before reuse;
- potentially useful later for open training/evaluation material, especially early-modern German/Latin-script handwriting.

References:
- https://htr-united.github.io/catalog.html
- https://github.com/HTR-United/htr-united

### DigiRef visitations corpus

- highly relevant genre/domain corpus for visitation records and surrounding administrative material;
- potentially valuable for formula/terminology discovery and locating analogous passages;
- portal accessibility is not equivalent to blanket open-data/open-image reuse;
- manuscript-image, metadata, bulk-access and publication/reproduction rights must be distinguished before any automated corpus ingestion.

Reference:
- https://digiref.reformationsportal.de/projekt-digiref/visitationsakten

## Questions this audit must answer

For each resource:

1. What exact scholarly problem can it help solve?
2. Is access manual-web, searchable endpoint/API, downloadable dataset, or only human-facing portal?
3. What license/terms govern:
   - ordinary scholarly lookup;
   - automated querying;
   - bulk download/scraping;
   - local indexing;
   - redistribution in this repository;
   - model training/fine-tuning;
   - publication of derived excerpts/images?
4. Can candidate results be recorded by stable citation/reference without copying the underlying resource?
5. What contamination risk exists if parallel or formulaic wording is shown before target-graph inspection?
6. Can the resource be used at zero recurring monetary cost?

## Preferred operating model

Start with **lookup/retrieval, not corpus ingestion**.

For FWB/DRW, the likely first use is targeted lexical verification/candidate discovery after graph localization. Persist citations/search terms/results needed to reproduce the research claim, not wholesale copied databases.

For DigiRef, start from metadata/search and explicitly authorized page inspection. Do not create a local bulk image corpus without rights evidence.

For HTR-United, select only datasets whose explicit licenses fit the intended evaluation/training use.

## Genre-specific opportunity

If rights/access permit later work, a visitation-specific retrieval layer could become a strong research aid:

- recurring administrative formulas;
- pfarrer/Pfarreinkommen/property obligations;
- land/wood/use clauses;
- measures/natural dues/accounting terminology;
- recurring institutional/legal wording.

Such retrieval would generate hypotheses and comparanda, not overwrite the diplomatic layer.

## Non-goals

- no blanket scraping of FWB/DRW/DigiRef;
- no assumption that free web access means Open Data;
- no automatic normalization of manuscript forms;
- no semantic completion of `⟦unclear⟧` spans from formula frequency;
- no model training from third-party material without explicit license compatibility;
- no new ontology or corpus platform from this audit alone.

## Definition of Done

Create a concise repository audit table/record covering at least FWB, DRW, HTR-United and DigiRef with:

- scholarly role;
- access mode;
- cost status;
- exact license/terms evidence where discoverable;
- permitted/prohibited/unclear reuse classes;
- recommended first low-risk use;
- whether any automated helper is justified.

The issue is complete when we can distinguish **free to consult**, **open/reusable**, and **safe for automated/local use** without conflating them.
