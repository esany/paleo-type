## Problem claim

The authoritative S1–S9 method is strong once source basis, relevant structure and transcription target are sufficiently known. It is not yet explicit enough about the adaptive condition in which a historical manuscript/archival unit is initially:

- internally unknown or composite;
- only partly relevant to the research question;
- difficult to read;
- not yet safely bounded into documentary units/loci;
- liable to require broad inspection before active scholarly scope can be formed.

Without a clearer generic source-entry method, a fresh context can prematurely freeze scope, read S2→S3→S4 too linearly, over-transcribe an archival root, or use `reconnaissance` as an undefined generic token rather than a source-critical activity.

## Desired outcome

Define the smallest generic, conditional **adaptive source-entry research cycle** that governs the move from an unfamiliar source to bounded, evidence-auditable scholarly work while reusing the existing S1–S9/G1–G6 method.

Conceptually the cycle must be able to cover, where required:

```text
owner-grounded purpose
→ revisable provisional editorial intent
→ exact source/file/access basis
→ broad source reconnaissance
↔ documentary/material structure hypotheses
↔ relevance discovery / exclusion / unresolved relevance
↔ palaeographic familiarisation + exact internal anchors
↔ pilot reading / pilot transcription
↔ Source/locus boundary adjudication where warranted
↔ active scholarly scope formation/revision
→ bounded diplomatic representation / later S4–S9 work
```

This is a hypothesis to refine/falsify, not a pre-authorized new stage model.

## Required semantics

The method must keep distinct:

- Project root / documentary anchor;
- discovery or inspection domain;
- actual inspection coverage and depth;
- discovered documentary structure;
- active scholarly research scope, including empty, multiple, disjoint and evolving Source/locus targets;
- pilot/diagnostic reading;
- G2 diplomatic transcription scope;
- historical/completed scope;
- current bounded `NEXT ACTION`.

It must also allow `no relevant locus found at the documented inspection coverage` as a valid outcome.

## In scope

- conditional trigger for an unfamiliar-source/source-entry mode;
- what source reconnaissance is for and how its depth is tied to the claim attempted;
- revisable **provisional editorial intent** rather than premature final edition conventions;
- explicit S2↔S3↔S4/pilot-reading iteration;
- unfamiliar-hand familiarisation as legitimate early source work;
- negative/unresolved relevance outcomes;
- simple-source fast path: a short clear single document must not inherit 250-page-survey bureaucracy;
- stress-testing on materially different cases: short charter, large composite file, difficult hand, multiple hands, register/account, later extract, related witnesses, missing images, expected relevance not confirmed;
- identifying where existing #265/#267 state is required without prescribing its physical schema.

## Out of scope

- no new universal S0 gate;
- no physical schema/table/YAML design;
- no universal document/genre/stage ontology;
- no universal hand/alphabet registry;
- no fixed Source hierarchy;
- no automatic relevance classification;
- no automatic copy/dependence detection;
- no Human UI implementation;
- no change to G1–G6 gate sequence merely to name this capability.

## Existing method to preserve

- `research goal → research question → evidence needed → disciplinary method → claim type → permitted conclusion`;
- evidence before plausibility;
- `OBSERVATION → READING → NORMALIZATION → IDENTIFICATION → INTERPRETATION` separation;
- scope-bound G1–G6 claims;
- flexible Source depth / Source-vs-locus rule;
- witness independence before collation;
- unresolved as valid;
- qualified specialist review when consequence warrants it.

## Required fixtures / Generic-Fit

At minimum test against:

1. one real large Wolkenburg archival unit once Human-authorized for the pilot;
2. one existing Reg.-Ii. source-work fixture;
3. one simple/short source case so the method demonstrates a lean fast path rather than mandatory ceremony.

## Acceptance criteria

- [ ] a fresh researcher can explain the first source-entry actions for both a clear one-page/short document and a 50–300-page composite unit without inventing two incompatible methods;
- [ ] source reconnaissance has an explicit purpose and claim-dependent sufficient depth;
- [ ] close/pilot reading can support handwriting/structure familiarisation without being mislabeled G2-complete;
- [ ] palaeographic familiarisation may iterate before/during complete G2 representation of the selected locus;
- [ ] broad inspection never automatically becomes active scholarly scope;
- [ ] active scholarly scope may remain empty, multiple, disjoint and evolving;
- [ ] inspected-and-excluded, unresolved-relevance and not-yet-inspected remain distinguishable;
- [ ] documentary boundaries may remain provisional until evidence warrants Source/locus decisions;
- [ ] the method identifies when downstream #265/#267/#266/#268/#269 work is triggered rather than embedding those representations here;
- [ ] no fixed ontology/workflow engine is introduced;
- [ ] any normative shared METHOD change receives explicit D-016 admission before implementation.
