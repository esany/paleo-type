## Problem / Gap
Project scholarship has resolver/context support, but system-development bootstrap still requires substantial manual composition. The Human needs a wider trustworthy overview than an Agent executing one bounded task; optimizing both as one context either creates blindness or context swamp.

## Findings covered
F01, F03, F04, F08, F14, F18, F20, F23, F27, F31, F34 plus new findings on Human-vs-Agent view separation and context-budget growth.

## Required effect
Design role/task-specific system-development context with:
- current authority/configuration/change first;
- explicit applicability provenance (derived where formal; selected with source/basis where judgement is required);
- progressive disclosure to Requirements/ADRs/evidence/history;
- a Human strategic/work overview distinct from Agent execution context;
- one clear Senior Developer entry path and one documented full local assurance command;
- measurable reconstruction-cost baseline/target.

## Next activity / readiness
**READY TO DESIGN. CONTEXT-COMPILER IMPLEMENTATION NOT ADMITTED.**

## Dependencies
#246 for current-configuration semantics; #245 for material-finding/evidence trace; current Project/outcome context patterns may be reused where fit is demonstrated.

## Acceptance / close condition
- Fresh system developer can locate current/proposed/admitted states without audit replay;
- Human can see bugwave/open work without loading Agent execution detail;
- Agent can load an adequate bounded task packet without default history loading;
- omitted/applicable context has provenance rather than silent manual selection;
- deeper provenance remains reachable on demand;
- benchmark records required entry files, historical files, manual joins and ambiguity before/after;
- no generated view becomes canonical authority.

## Non-goals
No mega-prompt as repository architecture; no autonomous planner; no requirement to load the whole repo; no hiding uncertainty/authority to save tokens.

## Whole-system return
Report reconstruction-cost delta, newly resolved context dependencies, affected ADRs and which implementation work becomes ready.
