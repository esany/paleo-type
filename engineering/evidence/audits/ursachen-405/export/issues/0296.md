## Incident

The Human selected a new archival source by supplying a concrete Sächsisches Staatsarchiv catalogue URL during the source-entry / Wolkenburg research context.

The valid higher-order scholarly cursor was the initial Source/provenance step: establish the archival/catalogue identity and provenance of the selected object, keep catalogue claims at catalogue level, and only then proceed to exact digital instantiation / visual evidence.

When one web-fetch path for the archive page failed, the assistant instead shifted the task to visual-evidence acquisition and asked the Human for a viewer/PDF/screenshot. It also stated too early that the supplied URL already satisfied the #293 Human pilot-selection prerequisite before verifying that the linked archival unit actually belonged to the #293 Wolkenburg selection and before securing its Source identity.

The Human had to correct the assistant back to provenance-first work.

## Concrete semantic failures

1. **Input mis-typing:** an archival catalogue URL was treated primarily as a route to pixels rather than first as provenance/identity evidence for the selected source.
2. **Action-local failure promoted upward:** one failed fetch path became a reason to change the immediate scholarly action.
3. **Downstream prerequisite pulled forward:** `vision-inspectable` evidence readiness was treated as the next concern before S1 catalogue/provenance work was complete.
4. **Human-routing burden:** the Human was asked for PDF/viewer/screenshot instead of the assistant first preserving the valid cursor and exhausting derivable read-only provenance routes.
5. **Authority inflation:** Human selection of "this linked object" was promoted to verified #293 fixture membership before archival identity/group membership was established.
6. **Repair lag:** after Human correction, the assistant explained the mistake before freshly re-grounding in repository owners, increasing drift instead of immediately returning to the canonical cursor.

## Why this is systemic / Generic-Fit

The failure does not depend on Sächsisches Staatsarchiv or Wolkenburg. The generic shape applies whenever a higher-order scholarly task contains lower-layer technical prerequisites, for example:

- catalogue/provenance lookup → one web route fails;
- manuscript transcription → one render/attachment path fails;
- bibliography verification → one database/API route fails;
- repository persistence → one write path fails;
- collation → one witness-access mechanism fails.

In each case, the technical failure may limit the affected action, but must not silently choose a new scholarly stage, Source, scope, priority or authority claim.
