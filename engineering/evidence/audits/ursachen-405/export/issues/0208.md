## Demonstrated programme-level learning

The original P0 analysis was not the main failure. It already exposed multiple interacting construction sites, including scientific-selection weakness, addressability bias, support dominance, competence compression, productive context-reactivation risk, premise-depth review limits, lean-down/function-loss risk and the asymmetry `strong bounded execution / weaker research framing`.

The later stages were deliberately narrower:

```text
P0 broad problem landscape
→ P1 bounded empirical Research
→ P2 bounded normative/efficacy disposition
→ one selected local residual arc
→ local Requirements / change / Result Review
```

Each narrowing step could be locally valid while still leaving other P0 families unresolved, efficacy-limited, evidence-limited or separately owned.

The missing/under-operationalized middle was **programme continuity / coverage reconciliation**:

- after local synthesis/result transitions, no durable active owner necessarily required the whole original material problem landscape to be re-accounted for;
- local `PASS`, `STOP`, or `no further change warranted` could therefore be read as whole-programme completion even when they only closed one arc;
- a correct local Result Review did not by itself guarantee feedback into a current whole-programme capability/maturity view;
- strong restartability for a bounded task did not guarantee restartability of the programme-level cursor;
- existing normativity could be treated too readily as practical adequacy even where the original issue was activation/efficacy/composition;
- positive scholarly abilities (transdisciplinary synthesis, productive context reactivation, question formation, specialist-prepared owner decision support) remained less operationally visible than negative guardrails;
- lean simplification/lifecycle cleanup had stronger checks for data/state loss than for loss of cognitive/review functions.

This is a **programme-level composition/continuity finding**, not evidence for one master root cause.

## Concrete historical manifestation

The post-#198 path demonstrates the risk:

```text
#198 bounded synthesis COMPLETE
→ #201 selected Arc B
→ #203/#204/#205 resolved and validated that one local Type-III residual
→ local downstream boundary = observe real use / STOP
```

That local boundary was valid for Arc B. It was not evidence that the original research-system programme was complete. #206 had to be created later to reconstruct this distinction explicitly, and #207 had to be admitted as a whole-map P3A synthesis.

Therefore:

```text
local arc completion != programme completion
local restartability != programme-cursor restartability
Requirement present != demonstrated operative capability
```
