## Text

This PR corrects the source-as-project abstraction introduced by merged PR #40 and carries the correction through the repository as a single coherent model change rather than a local patch.

## Core correction

A **project is a bounded historical investigation / source-unlocking undertaking over a coherent source group**. An archival record, source section, shelfmark, PDF, or digital instantiation does not automatically become a project.

The good anti-drift intent of PR #40 is retained: one fact has one canonical owner, consumers reference rather than copy, and source relationships remain distinct from research organisation. The failed `source-unit` / `research-scope` project-kind split is superseded.

## Structural changes

- removes the four artificial source-as-project directories created by PR #40;
- keeps `projects/ega-reg-ii-5-knau/` as the actual investigation;
- adds human-readable `projects/ega-reg-ii-5-knau/sources/sources.tsv` with the four distinct archival records, project roles, relevant loci, and primary exact file IDs;
- keeps both Reg. Ii 3 records separate despite their shared signature because they have different archival record IDs, titles, loci, contents, and evidential roles;
- reserves `projects/relationships.tsv` only for relations between genuine investigations; artificial Knau→source-unit relations are removed;
- moves reusable source-wide crosswalks to `corpus/source-data/<source_id>/`;
- separates the project source-group register from the project inspection log.

## Exact original PDF exports

The exact archive export used for research is explicitly a **first-class evidential/preservation asset**. `corpus/files.tsv` records original filename, SHA-256, coverage, preservation state, intended repository path, rights state, and notes.

Preferred repository location when lawful/authorised:

`corpus/source-files/<source_id>/original/<original-filename>`

A URL/URN is retained as provenance where useful but is not treated as equivalent backup. Originals must remain byte-identical; OCR/crops/renders are derivatives.

### Rights status and current public-repository blocker

The PDFs themselves state `InC/1.0` (Copyright In Copyright). This is a known rights status, not an unknown-rights state. The RightsStatements definition says the object is protected by copyright and/or related rights and may be used in ways permitted by applicable law; other uses require permission from the rights holder. It also explicitly states that the rights statement is **not a licence**.

Therefore the repository does not interpret `InC/1.0` itself as permission to republish the PDF bytes in this public GitHub repository. The four central exports are recorded as `preservation-blocked-public-redistribution`, with exact SHA-256 and intended repository paths. This is deliberately different from saying the rights are unclear: the rights statement is known, but public redistribution authority is not established by that statement alone.

The preservation model remains ready for the exact binaries once a lawful/authorised repository-integrated storage route is established. A portal URL or URN is not considered an equivalent preservation copy.

## Anti-drift invariant after this PR

`project = investigation`  
`source = archival/intellectual source record`  
`locus = project-relevant part of a source`  
`file/instantiation = exact digital representation`  
`source relationship = evidence-controlled corpus claim`  
`project relationship = relation between genuine investigations only`

A future researcher should be able to understand the investigation, its distinct source group, exact inspected exports/preservation state, current evidence/gate state, and next action without reconstructing chat or interpreting artificial source wrappers.
