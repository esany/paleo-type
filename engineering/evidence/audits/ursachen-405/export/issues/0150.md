## Purpose

Close the post-#140 comparison step before any F1 pixel work. Compare the already isolated Generator A (#141 same-source visual retrieval) and Generator B (#140 local HTR) by **problem type × downstream scholarly utility × effort × failure character**, not by a single tool score.

## Inputs

- #141 / `research/same-source-visual-retrieval-spike-2026-09-10.md`
- #140 / `research/local-htr-candidate-generator-spike-2026-09-10.md`
- #142 packet/context boundary remains unchanged
- #123 remains the scholarly owner; F1 remains untouched during this comparison

## Required comparison

Persist a small matrix covering at least: stable/recurrent form, variable/allographic form, number/sign ambiguity, segmentation/layout problem, longer uncertain word span, and name-like unresolved span.

For each problem type record:

- useful-candidate/discriminator yield supported by the isolated runs;
- time/setup/context burden where measured;
- primary failure character;
- whether B is genuinely complementary to A rather than merely different.

Do not reduce the result to `A > B` or one aggregate score.

## Decision boundary

Decide separately:

1. whether A remains KEEP narrowly;
2. whether B's marginal complementarity justifies its added setup/adjudication burden;
3. whether a combined A+B run is justified at all, and if so whether it must be a bounded sequential/conditional escalation rather than automatic fusion;
4. what prospective generator-selection rule, if any, may be carried into F1.

No new model, embedding system, HTR training, packet default, canonical reading, STATUS/Gate change or F1 source inspection is authorized by this issue.

## Prospective-test protection

The comparison may define the F1 protocol, but must not inspect or adjudicate F1 pixels. Because the current execution context has already seen the canonical F1 reading owner, any strict anti-hindsight F1 run must be handed to a genuinely fresh context that has not seen `62v.tsv` or equivalent derived/current-reading content before the blind observation/candidate stage.
