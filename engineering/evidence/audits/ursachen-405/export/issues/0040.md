## Text

This PR establishes the reusable multi-project model while preserving the finalized concurrent GitHub milestone-family governance now on `main`.

What changes:
- adds `methodology/project-lifecycle.md` with project kinds, creation invariants, project/source relation separation, anti-drift checks, activation/dormancy rules, and feedback loops;
- adds `templates/project/` as the minimal project contract; new projects must be instantiated from this template, never cloned from a pilot;
- adds canonical `projects/relationships.tsv` for research-organisational project relations only;
- distinguishes `source-unit` projects from bounded `research-scope` projects;
- creates source-unit projects for Reg. Ii 5 / 00000129, Reg. Ii 4 Bd. II / 00000089, Reg. Ii 3 / 00000235 and Reg. Ii 3 / 00000197;
- keeps the Knau benchmark as a `research-scope` project and links it to those source-unit projects with `scopes-source-unit`, `compares-with`, `uses-as-control`, and `uses-as-context`;
- moves reusable source-local crosswalks out of the Knau consumer project into their owning source-unit projects, eliminating duplicate canonical mapping;
- updates README and maintenance so project lifecycle, project relations, source ownership and the finalized Milestone families (`GOV-*` and `<project> / G*`) coexist without competing truth stores;
- records the project-model decision as **D-011**, preserving the finalized concurrent Milestone decision as **D-010**.

Critical separations:
- historical/archival/textual source relations remain canonical in `corpus/relationships.tsv`;
- research-organisational project relations live in `projects/relationships.tsv` and never prove source dependence/equivalence;
- generic G1–G6 requirements remain canonical in `methodology/research-gates.md`;
- actual evidence-based project gate state remains canonical in project `STATUS.md`;
- GitHub project-gate Milestones are planning mirrors only.

Exact archive PDFs remain external-to-git under the existing `corpus/files.tsv` policy; source identity, checksum/file provenance, crosswalks and derived scholarly work remain durable in the repository.

Anti-drift rule: one fact has one canonical owner; research-scope projects reference source-unit mappings rather than copying them. Source-level corrections flow through source-unit/corpus owners to affected related projects. Generic corrections require an explicit generalisability check before changing METHOD.

Concurrency reconciliation: the completed parallel governance/Milestone work from `main` has been explicitly incorporated into this branch; PR #40 is no longer based on the superseded pre-Milestone semantics.
