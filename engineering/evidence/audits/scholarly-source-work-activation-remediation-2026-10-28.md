## Implemented bounded change

`AGENTS.md` gains a concise **Scholarly source-work activation checkpoint** immediately after mandatory context loading.

For historical-source understanding, source criticism, transcription or edition outcomes it requires the active context to instantiate, before substantial support work:

```text
CURRENT OBSERVATION / UNCERTAINTY
→ BOUNDED SCHOLARLY QUESTION
→ GOVERNING DISCIPLINE / METHOD
→ EXACT EVIDENCE / LOCATOR NEEDED
→ CLAIM CEILING
→ FIRST SCHOLARLY ACTION
→ RETURN / REVIEW / SPECIALIST TRIGGER
```

The checkpoint also makes three demonstrated boundaries explicit at the activation point:

1. source-capable handoffs bind exact Source/File identity and evidence locator where deterministically resolvable;
2. inherited/candidate AI or PR observations do not become new primary-source evidence through repetition;
3. support work before the first scholarly action must directly enable that action or protect an invariant; resource absence remains action-local without dependency authority.

This is a projection of already existing `historical-source-workflow.md`, #292 semantics and `workflow.md`; it is not a new stage model.
