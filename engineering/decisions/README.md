# Engineering ADR surface

This directory records architecture rationale for SD-KA-01. It does not replace `DECISIONS.md`, Requirements, Issues or `engineering/configuration.json`.

- `DECISIONS.md` remains the accepted cross-project decision owner.
- A proposed or admitted-for-implementation ADR is not an accepted current baseline.
- Retrospective records explain a bounded change; they do not manufacture historical authority.
- Supersession, acceptance and rejection must remain explicit and traceable.
