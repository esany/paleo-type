# Independent first reading — Knau, fol. 306v–309r

This directory contains the **folio-local data partitions** for the independent Reg. Ii 4 first-reading work on the owner-selected Knau locus.

This README is a navigation aid. It does **not** create or own a scholarly parent entity and does not own Project scope, progress/completeness, current cursor, gate state or release authority. Those meanings are resolved from `../../project.yml`, `../../STATUS.md`, the project-local evidence lock and the generic research/transcription method.

## What belongs to each folio file

Each `*.tsv` file records the actual changing scholarly information for that folio:

1. `reading_order`;
2. `diplomatic_reading`;
3. `line_ref`;
4. `region` where materially relevant;
5. `source_phenomena`;
6. `research_status`;
7. graphically viable `alternatives`;
8. separate abbreviation/editorial-supply information where needed;
9. only consequential local `evidence_note` values.

Stable Source/File/image/PDF provenance remains recoverable from canonical Project/corpus/evidence owners rather than being copied into every row.

For difficult readings, the target graph/sign must be observed and localized first. Exactly locatable internal Reg. Ii 4 same-witness comparanda may then be used where graphically relevant under the project evidence lock. If such a comparison materially affects a consequential reading, preserve the exact anchor and concise reason in the owning folio record. Same witness/source is not by itself a same-hand claim.
