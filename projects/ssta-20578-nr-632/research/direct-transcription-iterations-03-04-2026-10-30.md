## Method/tool learning (evidence-limited)

1. **S2 must govern S3 on multi-view scans**: one PDF page or image number does not define a physical text unit; a catchword/continuation check can prevent a diplomatic double count.
2. A *physically addressed* 7-line span with a separate `K01` source phenomenon is more useful than an attractive but untraceable joined paragraph.
3. Distinguish `unclear` (positive but uncertain), `untranscribed` (out of scope), `gap/illegible` (actually inspected illegible), and a Kustode candidate. Do not merge them into `[...]`.
4. **Already sufficient tooling:** file hash, PDF image extraction, lossless region crops, contrast-only viewing, typed JSON candidate, visible side-by-side PDF and post-render page review.
5. **Observed ergonomic gap:** no integrated region/line/source-phenomenon editor with adjacent views, per-reading grapheme evidence, and versioned candidate→adjudication diff. This is a candidate usability need, not a generic software requirement or authorization to implement OCR/HTR.
6. One model re-reading its own output is **not independent review**. This test's source crops are direct P evidence but its palaeographic conclusions remain AI working judgements.
