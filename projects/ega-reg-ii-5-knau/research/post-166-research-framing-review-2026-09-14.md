## 4. Why the recent scientific trajectory looked like stagnation

The project accumulated increasingly strong local evidence control and increasingly precise bounded work packages, yet domain-specific knowledge growth could still feel incremental.

The principal failure mode was not simply `too much process`. It was the interaction of several effects:

### 4.1 Addressability bias

The system was naturally drawn to questions already represented as:

- unresolved line/locus;
- repeated name/form;
- numeral/sign;
- cancellation;
- existing comparison candidate;
- checklist/backlog item.

These are easy to localize, verify and close. That does not make them the highest-information historical questions.

### 4.2 Research-address / analysis-unit collapse

Physical `line_ref`, paragraph/layout block, correspondence range, research locus, analysis unit and functional rule were repeatedly at risk of becoming the same practical object.

L021/L022 and #165/#166 corrected the strongest recent instance: a G4 correspondence range was incorrectly promoted into one target-witness cross-folio unit.

### 4.3 Assurance amplification

Once a bounded scope existed, access/provenance/testing/support work could protect and amplify it even if the scope itself deserved re-framing. L024 correctly separates **scope correctness** from **execution economy**.

### 4.4 Resource/authority laundering

The later #166 PDF-access incident demonstrated a separate execution failure: resource unavailability became task blocker and then roadmap STOP without independent authority. #169/PR #175 corrected this generically.

These later process failures were real, but they should not replace the earlier scientific question: **was the selected domain-specific research question itself the most consequential one?**

## 8. What should remain bounded to this Project versus generic

### Project-specific

- actual Reg. Ii 5 / Knau-related readings and source structure;
- current source-understanding synthesis;
- contextual historical leads and their evidence status;
- which Knau-related question the Human Owner chooses next;
- whether a specific unresolved relation materially changes interpretation;

### Generic

- distinguish Project / Source / research locus / source-native structure / analysis unit;
- activate disciplines according to the question and source, not by fixed universal sequence;
- let expertise generate questions/tests without manufacturing source evidence;
- preserve semantic/authority boundaries when translating between disciplines and technology;
- do not let existing artifact topology choose research priority;
- compare candidate research questions by scientific consequentiality rather than mere addressability;
- Human Owner retains purpose/priority authority;
- technical work remains subsidiary to established scholarly information requirements.

No Knau-specific unit or visitational source taxonomy should become universal architecture solely from this fixture.

## 9. Research-framing function that is missing from the current visible Project path

The present Project state is excellent at saying what is complete and what must **not** auto-start.

It is less explicit about the constructive step between completed synthesis and the next owner decision.

A useful non-normative framing surface would compare candidate questions using at least:

```text
CURRENT PROJECT PURPOSE
CURRENT SOURCE-UNDERSTANDING DELTA
SOURCE-NATIVE STRUCTURE RELEVANT TO THE QUESTION
IMPLICATED SCHOLARLY COMPETENCIES
WHAT EACH COMPETENCE CAN / CANNOT DECIDE
CONTEXT THAT MAY NOW ENTER WITHOUT CONTAMINATING READING
COMPETING / COMPLEMENTARY QUESTION FRAMES
EXPECTED SCHOLARLY INFORMATION GAIN
WHICH RESIDUALS WOULD ACTUALLY CHANGE THE ANSWER
EVIDENCE NEEDED
KNOWN EVIDENCE CEILING
OWNER-RESERVED PRIORITY CHOICE
```

This should not become a mandatory form. It describes missing semantics that a competent review should reconstruct before recommending the next consequential scope.

## 11. Review conclusion

The Project has not simply `lost the plot`, but it has repeatedly risked converting useful support structures into research-direction authority.

The strongest retained insight is:

> **The next scientific scope should be derived from Project purpose + current source understanding + source-native structure + relevant disciplinary perspectives, not from whichever unresolved locus, artifact directory, comparison range, available tool or support condition is easiest to address.**

The strongest correction to avoid is the opposite overreaction:

> **Do not respond to micro-fragmentation by automatically enlarging the source scope.**

A bounded Knau-related locus can remain the priority while its internal research framing becomes more historically and transdisciplinarily sophisticated.

The generic tool must support that same operation for a 1920 letter, a seventeenth-century military recruitment account or another source type without importing Knau-specific structure.
