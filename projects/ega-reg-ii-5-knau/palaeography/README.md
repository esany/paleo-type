# Palaeography directory — current role

This directory is retained for historical/recovery value. It is **not** a current Reg. Ii 5 witness-reading owner and it is not an instruction to build a project-wide palaeographic lexicon or concordance.

Current authority is artifact-specific:

- `lexicon.tsv` is legacy verification/recovery material. Its project-local word/form entries do not establish current Reg. Ii 5 readings, exact comparison anchors or same-hand evidence.
- `numerals.tsv` is likewise legacy verification/recovery material except where an entry is explicitly bound to a different exact Source/locus, such as the Reg. Ii 3 C2 comparison observation. Such an entry retains only the authority stated for that concrete Source/locus.
- The authoritative classification and promotion limits are owned by `../research/legacy-witness-provenance.tsv`.
- Current Reg. Ii 5 diplomatic readings are owned by `../transcription/first-reading/*.tsv`.
- The completed bounded internal palaeographic/notational analysis for fol. 61v–63r is owned by `../research/g3-internal-review-61v-63r.md`.

For future comparison work, start from a concrete consequential unresolved target, formulate the graphical/notational question, then seek exactly localized relevant comparanda. A comparison locus may test a target reading; it does not become a substitute reading. Same Source, record or textual environment is not same-hand evidence.

Do not extend these legacy tables merely because similar forms exist. Create additional structure only if real source work demonstrates that the current canonical representation would otherwise lose consequential evidence or repeated cross-project reuse genuinely requires a different owner.
